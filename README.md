# 🌱 The Cozy Kitchen

A cozy, cottagecore recipe site for collecting my favorite recipes.

**Live site:** [demsingh30.github.io/cozy-kitchen](https://demsingh30.github.io/cozy-kitchen)



## Built With
- HTML
- CSS (Flexbox, Grid, animations)
- JavaScript 

## Features
- Recipe cards with a taped-polaroid look and a hover lift
- Colorful tag pills (cuisine, difficulty, one-pot)
- Search bar and hero section with a fade-in
- Submit a Recipe form
